# Плитка.План — демо-версия для продажи

Калькулятор стоимости плитки с интерактивным 3D-чертежом на Three.js, переходами на GSAP и кабинетом владельца. Цены и образцы демонстрационные. Валюта каталога — украинская гривна. Сумма включает плитку по площади с опциональным запасом 10%. Чертёж показывает условную раскладку прямоугольника с пропорцией 5 к 4.

## Запуск

Нужен Node.js 24. Создайте `.env` на основе `.env.example` и задайте `OWNER_PASSWORD`, затем выполните:

```sh
npm ci
npm run build
npm start
```

Калькулятор доступен на `http://127.0.0.1:4173`, кабинет — по адресу `http://127.0.0.1:4173/owner`. Локальные заявки хранятся в `.data/leads.sqlite`. Для приёма заявок на опубликованном сайте используется привязка Cloudflare D1 `DB` и миграции из `drizzle/`. Пароль для опубликованного кабинета задаётся в среде Sites через `OWNER_PASSWORD`.

Клиент отправляет заявку сразу в кабинет владельца. В заявке остаются контактные данные, выбранный материал, площадь, запас, цена за м², итоговая сумма и комментарий. Сервер рассчитывает сумму повторно по каталогу `src/catalog.js`. Цены и форматы можно заменить в каталоге, а образцы — в `src/textures`.
